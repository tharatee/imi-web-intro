# IMI Web Intro

## Project Description

This project was created as part of Practical Assignment No. 0:
Introduction to Modern Web Development.

The project demonstrates basic frontend development using HTML,
CSS and JavaScript.

The website retrieves posts from an open REST API and displays
them dynamically on the page.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Fetch API
- JSON
- Git
- GitHub

## API

The project uses JSONPlaceholder.

API endpoint:

https://jsonplaceholder.typicode.com/posts

HTTP method: GET

No API key is required.

## Project Structure

- index.html - Main HTML structure.
- style.css - Website styling.
- app.js - API requests and dynamic content.
- README.md - Project documentation.
- .gitignore - Files excluded from Git.

## How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension.
4. Right-click index.html.
5. Select Open with Live Server.
6. The website will open in your browser.

## Features

- Retrieves posts using the Fetch API.
- Uses an asynchronous GET request.
- Displays a loading message.
- Handles HTTP and network errors.
- Displays posts dynamically.
- Includes a reload button.
- Supports responsive design.
